# Frontend note

The full production `index.html` (~95KB) lives in the local project workspace.

To add it to this repo from your machine:

```bash
git clone https://github.com/Rustys90/airlines-travel.git
cd airlines-travel
# copy your index.html into this folder, then:
git add index.html
git commit -m "Add production frontend"
git push
```

Or open the repo on GitHub → Add file → Upload the `index.html` from your project.
